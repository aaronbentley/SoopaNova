## Steam app

The Steam app provides an integrated system that organizes and allows easy access to your captured in-game moments.

1. **Open Steam:**
    - Open Steam on your device.
    - Click on _"View"_ on the menu bar, then _"Screenshots"_ from the drop-down menu.
2. **Access screenshots:**
    - Click on the desired screenshot.
    - Click the _"Show on Disk"_ button to open the file explorer in the directory where the screenshot is stored.

## File system

To locate Steam screenshots via the file system, you can navigate to the Steam folder where the screenshots are stored.

1. **Open the Steam directory:**
    - Finding and opening Steam's installation directory depends on the operating system you're using:
        - On Windows, the default is _"C:\Program Files (x86)\Steam"_.
        - On a Mac, the default is _"Users/[your-mac-username]/Library/Application Support/Steam"_.
        - On a Linux system, the default is _"~/.local/share/Steam"_.
    - If you have changed the default installation directory or customized your Steam settings, you may need to adjust the path accordingly.
2. **Go to the screenshots folder:**
    - Within the Steam installation directory, look for a folder named _‘userdata’_. The exact path might vary based on your Steam account ID. Typically, it is found in a structure like:\
      _‘userdata\\[your-steam-ID]\760\remote\\[app-ID]\screenshots’_.
    - The **[your-steam-ID]** part will be a numerical value unique to your Steam account.
    - The **[app-ID]** is the application ID of the game for which you want to access screenshots. Each game on Steam has a unique ID.
3. **Access screenshots:**
    - Inside the _‘screenshots’_ folder, you should see subfolders named with numbers, each corresponding to a different game.
    - Locate the folder for the specific game you're interested in.
    - Inside the game's folder, you should see a list of all the screenshots for that game.
